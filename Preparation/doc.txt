Q- how React reconciliation works?
    React uses virtual dom is a copy of actual DOM tree, 
    using diffing algroithm, whenever any state or props changes in the application, 
    it compares the new vitual dom with the previous one and identofy which element has changed.
    and instead of updating whole DOM tree it only updates the element which are added/removed.

Q- What is an event loop?(while answers include macro and micro queue both).
    Event loop is a JavaScript runtime mechanism that enables asynchronous programming by constantly monitoring the call stack
    and task queues, allowing the single-threaded engine to handle tasks without blocking the main thread. It executes synchronous 
    code first, then fully processes all tasks in the microtask queue (high priority, e.g., Promises) before handling one macrotask
    (e.g., setTimeout).

Q- useEffect vs useLayoutEffect?
    useEffect runs after paint and non-blocking(asynchronous), used for api calls, timers, subscr.
    wherease layout runs before paint and blocking, use only when we need to measure or mutate the dom synchronous.
    useEffect -> Render - Paint - useEffect
    useLayoutEffect -> Render - useLayoutEffect - Paint ( runs synchronous after react perform all dom mutate, but before browser paint)
